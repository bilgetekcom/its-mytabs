# GeneralUser GS 2.0.3

Default local playback bank, by S. Christian Collins. General MIDI instrument
assignments from imported scores are preserved; this bank changes their timbre.
It does not turn programmed MIDI notes into a recorded human performance.

Retain the full license and attribution when redistributing this bank.

The original Sonivox bank remains available in Settings as a smaller alternative
and is tried automatically if GeneralUser GS cannot load. Both banks are bundled
locally; playback does not fetch sound samples from a third-party CDN.
